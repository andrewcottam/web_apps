# Running
```
cd openlayers/tms
npm install
npx vite
```

# Building
This builds the dist folder ready for deployment using the base name in the vite.config.js file to set the relative path.
```
cd openlayers/tms
npm run build
```

# Deploy
The github pages for the web_apps repo are built automatically and deployed to https://andrewcottam.github.io/web_apps/.
