# Background 
This folder contains an OpenLayers client for showing the TMS/MVT tiles from a local server

# Start the tornado web server
See the local_app/server/README.md file for instructions on starting the local web server

# Installing 
```
cd openlayers/app
npm install
```

# Running
```
cd openlayers/app
npx vite
```

# Building
```
cd openlayers/app
npx vite
```

Goto
http://localhost:5173/

The mb_index.html file is a MapBox map client - currently only mapping the TMS tiles.
