Data Source & Citation

This report uses vegetation disturbance data from NASA's OPERA DIST-ALERT (Observational Products for End-Users from Remote Sensing Analysis - Disturbance Alert) product. OPERA DIST-ALERT provides near real-time detection of land surface disturbances using Harmonized Landsat Sentinel-2 (HLS) data at 30-meter resolution.

Citation: Nguyen, T.H. et al. (2025). OPERA DIST-ALERT: Near-real-time disturbance detection in HLS satellite images. Nature Communications. https://www.nature.com/articles/s41467-025-64014-9

Satellite imagery previews use Landsat Collection 2 Level-2 data (Landsat 5, 7, 8, 9) produced by NASA/USGS and accessed via Microsoft Planetary Computer. Landsat imagery courtesy of the U.S. Geological Survey.

Satellite imagery previews also use Sentinel-2 Level-2A data produced by ESA/Copernicus and accessed as Cloud-Optimized GeoTIFFs via AWS Earth Search (managed by Element 84). Access to Sentinel data is free, full and open under the Copernicus Terms and Conditions.
